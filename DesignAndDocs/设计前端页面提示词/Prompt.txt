请求URL：GET /api/models

{
  "success" : "bool",                # 是否成功 
  "message" : "string",              # 结果描述
  "data":                            # 响应数据
      {

          "session": "string"                #会话名称
      }
}

4. 发送消息 - 流式响应
请求URL：POST /api/message/async
请求参数：
{
  "session_id" : "string",        # 会话id
  "message" : "string"           # 消息内容
}
返回响应：200 OK
流式响应，格式如下
data: 正文\n\n
data: 正文\n\n
data: 正文\n\n
data: [DONE]

5. 删除会话
请求URL：DELETE /api/session/${session_id}
返回响应：200 OK
响应格式
{
  "success" : "bool",         # 是否成功

}

6. 获取会话历史
请求URL：GET /api/session/${session_id}/history
返回响应：200 OK
响应格式
{
  "success" : "bool",
  "message" : "string",
  "data": "array"[
    {
      "id" : "string",
      "role" : "string",
      "content" : "string",
      "timestamp" : 0,
    }
  ]
}
