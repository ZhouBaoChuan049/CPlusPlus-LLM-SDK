六、设计密码哈希
直接放在ChatServer中，你需要设计一套简易的密码哈希算法。以便我们用户输入的密码可以安全存放在数据库中。
Argon2id 是一种专门用来“存密码”的密码哈希算法。你需要实现一套简化版本的。比如我举个例子：
std::string SimpleArgon2id(const std::string& password,
                           const std::string& salt){
    std::hash<std::string> hasher;
    std::string data = password + salt;
    // 模拟 Argon2id 的多轮计算
    for (int i = 0; i < 100000; ++i)
        data = std::to_string(hasher(data + salt + std::to_string(i)));
    // 转成十六进制字符串
    std::stringstream ss;
    ss << std::hex << hasher(data);
    return ss.str();
}
于是我们得到了哈希转化后的“密码”。

六、回到的ChatServer

通过_chatsdk填入会话管理类中进行维护。如果不一致，调用UserManager中的插入新用户信息方法。将用户名和密码放入数据库中长期存储。
